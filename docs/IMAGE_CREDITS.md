# FreshFind Image Assets

FreshFind uses lightweight local SVG illustrations for each produce item and each market card so the project remains self-contained and works without an image CDN.

Market card illustrations are visual representations of a farmers-market setting with the relevant Karachi area/market name; they are not presented as verified photographs of the exact physical location.
